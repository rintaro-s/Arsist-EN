# プレゼン録画 — `presentation-recorder`

Quest をかぶって **VRM の姿でプレゼンをし、その様子を動画にする** 見本 (Layster.Virtual β 1.1.0、`irVersion` 7)。
PC の画面 (スライド) を巨大なスクリーンに映し、仮想カメラで「発表者 + スクリーン」を撮って、Quest の
`Movies/Arsist/` に MP4 で保存する。使っているのはどれも汎用の部品 (doc/23-cameras-media.md) で、
このアプリ専用の機能はエンジンに無い。

| 使っているもの | どこで |
|---|---|
| 仮想カメラ (`type: "camera"`) | シーンの `Cam` |
| 画像に映すもの (`source`) | スクリーン・カンペ = PC からの配信 (`stream`)、モニター = カメラの鏡 (`camera` + `mirror`) |
| 自分の体 (`character.embody`) | シーンの `Me` (VRM 1.0 → 拡張機能 `vrm10`) |
| 録画 (`recorder`)、コントローラー、マイク | 拡張機能 `quest-input` |
| 画面の配信・スライド送り | PC で動かす `products/ScreenCast` |

## 置き方 (Virtual の座標。原点 = 起動したときの目、+Z 前、+X 左)

```
                 [モニター]  [カンペ]          ← z ≈ 5.3 m。カメラのすぐ後ろなので写らない
                      📷 Cam                    ← 前やや左 (x 0.3, z 4.8)。発表者とスクリーンの間を向く
                        ╲
                         ╲   (撮る範囲)
 [ スクリーン 4.8×2.7 m ]   🧍 自分 (VRM)        ← スクリーンは右に 3 m、カメラの方を向けて斜めに立つ
                         [手元の板]             ← 録画中は隠す
```

- **発表者はスクリーンの横に立ち、カメラの方を向いて話す。** だからスクリーンは「目の前」ではなく右横にある
  (目の前に置くと、カメラに写るのは発表者の背中かスクリーンだけになる)。スクリーンを見るときは右を向く。
- 正面 (カメラの後ろ) の **モニター** は撮っている映像を鏡にして映す。自分 (VRM) とスクリーンがどう写っているか、
  今どのスライドかが分かる。その右の **カンペ** は PC から配信される 2 本目の画面 (`notes`)。
- 手元の板 (アドレス・録画・スライド送り) は写ってしまう場所にあるので、録画を始めると隠れ、止めると戻る。
- 配置は「写るべき物は写り、モニターとカンペは写らない」ことを計算で確かめてある (カメラの縦の画角 48°、16:9)。
  カメラの向きは起動時に `cameras.lookAt` で合わせ直す。

## 準備

1. **PC**: `products/ScreenCast` を起動する (`products/ScreenCast/README.md`)。
   - 配信 `slides` に **スライドを映している画面かウィンドウ**、`notes` に **カンペ (発表者ツールなど)** を選んで「配信開始」
   - 右側に出る **PC のアドレス** (例 `192.168.0.12:8090`) を覚えておく
   - ファイアウォールでポート 8090 (TCP) を許可する
2. **エディタ**: このフォルダを開き、拡張機能 `quest-input` (samples/extensions。`npm run ext:link -- samples/extensions`) と
   `vrm10` が有効なことを確かめて、Meta Quest 向けにビルドして入れる。
3. **Quest**: アプリを起動する。手元の板のキーボードで PC のアドレスを打って **Enter**
   (ポートを省くと `:8090`)。端末に覚えるので次からは要らない (`project.storage.persist` = `pc.address`)。
   板の下に「PC につながりました: slides, notes」と出て、スクリーンとカンペに PC の画面が映る。

## 使い方

| 操作 | ボタン (手元の板 / モニターの下) | コントローラー |
|---|---|---|
| 録画開始 / 停止 | ● 録画開始 / ■ 録画停止 | 左 **X** |
| 一時停止 / 再開 | — | 左 **Y** |
| 次 / 前のスライド | 次 ▶ / ◀ 前 | 右 **A** / 右 **B** |
| カメラの向き | — | 左スティック |
| カメラのズーム | — | 右スティック 上 (寄る) / 下 (引く) |
| カメラを動かす | — | 左グリップを握りながら左スティック (前後左右)・右スティック (上下)。カメラを手でつかんで動かしてもよい |
| カメラを最初の位置に | 「カメラを戻す」 | — |
| スライド・モニター・カンペ・カメラを動かす | — | コントローラーを向けてグリップでつかむ (遠くからでも)。動かした分だけ動き、持っている手のスティック上下で奥 / 手前 |
| 手元の板を出す / 隠す | — | 左 **≡** (メニュー) |
| 背の測り直し | 背を測り直す | — (まっすぐ立って前を見てから押す) |

- スライド送りは PC で → / ← キーを押す (`POST http://<PC>/control`)。PowerPoint・Keynote・Google スライド・PDF ビューアなど、
  **キーで進むアプリを PC の前面にしておく**。
- 録画中はモニターの下と手元の板に `● REC 01:23` (`rec.label`。中身は `input.recorder.state` と `input.recorder.seconds`) が出る。
- 声はマイクから録音され、VRM の口も声に合わせて動く (`micAutoStart` を on にしてある。初回はマイクの許可を求める)。
- 録画は仮想カメラの映像だけ。パススルー (現実の部屋) は写らず、背景はカメラの `backgroundColor` で塗られる。

## 動画の取り出し

保存先は Quest の **`Movies/Arsist/Arsist_<日付>_<時刻>.mp4`** (H.264 + AAC、1920×1080、30 fps、8 Mbps ≈ 1 分 60 MB)。

- Quest の「ファイル」アプリ → ムービー → Arsist
- USB で PC につなぎ、Quest 内で「データへのアクセスを許可」→ `内部共有ストレージ/Movies/Arsist/`

保存先のフォルダ名・ビットレート・最長 (既定 60 分で自動的に止めて保存) は、拡張機能 `quest-input` の設定
(`recorderFolder` / `recorderBitrate` / `recorderMaxMinutes`) で変えられる。

## 中身

| ファイル | |
|---|---|
| `project.json` | プロジェクト。シーン 1 つ・UI 4 つ (Slides / Monitor / Notes / Setup)・スクリプト 1 つ (「プレゼン録画」) |
| `Scenes/*.json` / `UI/*.json` | シーンと UI の写し (`project.json` の中と同じ内容。doc/09 "Two copies") |
| `Assets/Models/avatar.vrm` | 自分の体にする VRM 1.0 (16 MB、作者 Rinta、再配布可)。好きな VRM に差し替えてよい (VRM 0.x なら `vrm10` は要らない) |

## 制限

- ScreenCast にトークンを設定すると、この見本からはつながらない (URL に `?token=` を入れていない)。家の LAN ではトークンを空にする。
- MJPEG は HTTP (暗号化なし) で、同じ LAN の中だけを想定している。
- 実機での動作 (録画・体の動き・配信の受信) は、この見本を作った時点では確かめていない。最初は `npm run logs` で
  `[presentation]`・`[Arsist:quest-input] recorder:`・配信の状態 (`media.slideImg.status`) を見る。
