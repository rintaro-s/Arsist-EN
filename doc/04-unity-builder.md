# UnityBuilder — `src/main/unity/UnityBuilder.ts`

Extends `EventEmitter`. Orchestrates the full headless Unity build pipeline from IR to APK.

---

## Constructor & Configuration

```typescript
new UnityBuilder(unityPath: string)
```

| Method | Purpose |
|--------|---------|
| `setUnityPath(p)` | Update the Unity binary path |
| `getUnityPath()` | Return current path |
| `setSdkDir(dir)` | Override the `sdk/` directory |

## Events Emitted

| Event | Payload | Description |
|-------|---------|-------------|
| `'log'` | `string` | Single build log line |
| `'progress'` | `BuildProgress` | Phase/percentage/message update |

`BuildProgress`:
```typescript
{ phase: string, progress: number, message: string }
```

## `build(config)` — Main Entry Point

```typescript
async build(config: UnityBuildConfig): Promise<BuildResult>
```

**`UnityBuildConfig`:**
```typescript
{
  projectPath: string          // Arsist project root
  sourceProjectPath?: string   // alias for projectPath
  buildTarget: 'Android'
  targetDevice: string
  outputPath: string
  developmentBuild: boolean
  buildTimeoutMinutes?: number // default 60
  logFilePath?: string
  manifestData?: object        // generated by UnityBridge
  scenesData?: object[]
  uiData?: object[]
  scriptsData?: object
  unityVersion?: string
}
```

**Return value:**
```typescript
BuildResult {
  success: boolean
  outputPath?: string   // absolute path to .apk or .aab
  error?: string
  warnings?: string[]
  buildTime?: number    // ms
  fileSize?: number     // bytes
}
```

## Build Phases

### Phase 1 — Validate (`prepare-unity`, 0–10 %)

- Verifies the Unity binary exists and is executable.
- Extracts and compares the Unity version string (`validate()`).

### Phase 2 — Prepare Jint DLLs (`prepare-jint`, 10–20 %)

- Looks for `Jint-*.nupkg` and `Acornima-*.nupkg` in `sdk/nupkg/`.
- If not present in the template project's `Assets/Plugins/`, downloads or extracts from nupkg.
- Copies `Jint.dll` and `Acornima.dll` into `Assets/Plugins/`.
- Resolution order: `netstandard2.1` → `netstandard2.0` → `net6.0` → recursive fallback search.

### Phase 3 — Prepare Unity Project (`prepare`, 20–30 %)

- Resolves `UnityBackend/ArsistBuilder/` template (relative to the Arsist repo root or `process.resourcesPath`).
- Copies the template to a working directory under the system temp folder (or user-specified `outputPath`).
- Writes `AndroidExternalToolsSettings.asset` with detected JDK/SDK/NDK paths.

### Phase 4 — Transfer Data (`transfer`, 30–50 %)

Writes into `Assets/ArsistGenerated/`:
- `manifest.json` — merged manifest + scenes
- `scenes.json` — scene objects array
- `ui_layouts.json` — UI layout array
- `dataflow.json` — DataFlow definition
- `scripts.json` — script bundle (if `scriptsData` is present)

Also copies `<projectPath>/Assets/` → `Assets/ArsistProjectAssets/`.

### Phase 5 — Apply Device Patch (`patch`, 50–60 %)

Delegates to `applyDevicePatch(unityProjectPath, targetDevice)`:
1. Resolves the adapter directory (`Adapters/<device>/`).
2. Applies `AndroidManifest.xml` to `Assets/Plugins/Android/`.
3. Copies `.cs` editor scripts to `Assets/Arsist/Editor/Adapters/<device>/`.
4. Copies `Packages/` entries.
5. Always calls `ensureAndroidCleartextHttpPolicy()` to patch `android:usesCleartextTraffic="true"`.

### Phase 6 — Integrate Required SDKs (`sdk`, 60–70 %)

- **XREAL target** (`isXrealTarget`): copies `sdk/com.xreal.xr/package/` → `Packages/com.xreal.xr/`, adds `file:com.xreal.xr` to `manifest.json`, injects required Unity module dependencies (`com.unity.ugui`, `com.unity.textmeshpro`, etc.).
- **Quest target** (`isQuestTarget`): copies `sdk/quest/com.meta.xr.sdk.core-*.tgz` (and optionally mruk) into `Packages/`, updates `manifest.json`, applies Quest XR bootstrap assets from the sample project.

### Phase 7 — Execute Build (`build`, 70–90 %)

Spawns Unity directly (no shell):

```
Unity.exe
  -batchmode -nographics -quit
  -projectPath <working-dir>
  -executeMethod Arsist.Builder.ArsistBuildPipeline.BuildFromCLI
  -buildTarget Android
  -outputPath <outputPath>
  -targetDevice <device>
  -developmentBuild true|false
  -arsist-jdk <jdk-path>
  -arsist-android-sdk <sdk-path>
  -logFile <log-file>
```

Environment variables injected: `HOME`, `JAVA_HOME`, `ANDROID_HOME`, `ANDROID_SDK_ROOT`, `PATH` (with JDK `/bin` prepended).

## Retry Logic

After a failed Unity invocation, the build is retried up to **5 times** using progressively different strategies:

| Attempt | Strategy |
|---------|---------|
| 1 | Default (batchmode + nographics) |
| 2 | noGraphics=false (render thread available) |
| 3 | Find and use a local `.ulf` license file from `~` or project dir |
| 4 | batchMode=false (windowed Unity, only on Windows) |
| 5 | Last-resort retry |

Licensing errors are detected by `isLicensingNoise()` which pattern-matches strings like `"No valid Unity Editor license"`, `"UnityLicensingClient"`, etc. Only licensing-only failures trigger the retry cycle — real compilation errors are returned immediately.

## APK Discovery — `verifyBuildOutput()`

Searches for the output APK in this order:
1. `<outputPath>/<projectBaseName>.apk`
2. `<outputPath>/<projectName>.apk`
3. `<outputPath>/build.apk`
4. `<outputPath>/ArsistApp.apk`
5. All `.apk` / `.aab` files in `outputPath`, newest-first
6. Recursive sub-directory search up to 5 levels deep, newest-first

Only files newer than the build start time (`sinceEpochMs`) are accepted.

## Android Toolchain Detection

### JDK — `detectJdkPath()`

Priority:
1. Unity bundled OpenJDK (`Editor/Data/PlaybackEngines/AndroidPlayer/OpenJDK/`)
2. `JAVA_HOME` environment variable
3. `JDK_HOME` environment variable

### Android SDK — `detectAndroidSdkPath()`

Priority:
1. Unity bundled SDK (`Editor/Data/PlaybackEngines/AndroidPlayer/SDK/`)
2. `ANDROID_HOME` / `ANDROID_SDK_ROOT` environment variables
3. `%LOCALAPPDATA%\Android\Sdk` (Windows) / `~/Library/Android/sdk` (macOS) / `~/Android/Sdk` (Linux)

If the detected SDK is under a Windows protected root (Program Files) or is not writable, it is **mirrored** to `userData/android-sdk-cache/<unity-version>/<source-key>/` before being passed to Unity.

## Unity Log Parsing — `readUnityLogIssues()`

Reads the Unity log file line-by-line and classifies each line:

- **Error** — lines matching `(^|\s)error(\s|:)`, `Exception\s*:`, or `BuildFailedException:`
- **Warning** — lines matching `(^|\s)warning(\s|:)`
- **Licensing noise** — filtered out before error classification

`pickBestError()` prefers: C# compiler errors (`error CS\d+`) > `BuildFailedException` > non-licensing errors > anything else.

---

## Windows Shell Compatibility — `ensureWindowsShellAvailability()`

On Windows, searches for `powershell.exe` in PATH and common install locations (PowerShell 7, System32 WPS), then prepends its directory to `PATH`. This ensures Unity's internal build scripts can invoke PowerShell during `Expand-Archive` (nupkg extraction) and Gradle invocations.

---

## `validate(expectedVersion?)` — Pre-Build Check

1. Verifies the Unity binary exists.
2. Invokes Unity with `-version` flag.
3. Compares the reported version against `expectedVersion` (if provided).
4. Returns `{ valid: boolean, version?: string, error?: string }`.
